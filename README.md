# Game of Thrones Script Analysis

An interactive data visualization project that analyzes the "Game of Thrones" scripts using **R** and **R Shiny**. 
This project explores character dialogues, sentiment trends, and word frequencies, providing meaningful insights through an engaging and user-friendly dashboard.

---

## Features

- **Interactive Dashboard:**
  - Built using **R Shiny** with a custom UI designed with the **bslib** package.
  - Includes advanced interactive features for seamless data exploration.

- **Text Mining and Sentiment Analysis:**
  - Used **tidytext** to analyze the sentiment of character dialogues and uncover emotional trends across episodes.
  - Conducted frequency analysis to identify commonly used words and phrases.

- **Data Visualization:**
  - Leveraged **tidyverse** and **plotly** to create interactive plots and visualizations for enhanced user engagement.
  - Presented key data insights with **DT** tables and additional UI components via **shinyWidgets**.

---

## Technologies Used

- **Programming Language:** R
- **Libraries:** Shiny, bslib, tidyverse, tidytext, plotly, DT, shinyWidgets
- **Tools:** RStudio

---

## Key Insights

- **Character Dialogues:** Visualized word frequencies and sentiment trends to understand character traits and emotional arcs.
- **Episode Analysis:** Explored how sentiment fluctuates throughout episodes and seasons.
- **Dashboard Usability:** Enabled users to filter, sort, and interact with the data to draw their own conclusions.
